# chenyanchen.github.io

The homepage at https://chenyanchen.github.io/, linking the projects published from their own repos:

- [Sudoku Solver](https://sudokusolver.siliconseries.com/) — [source](https://github.com/chenyanchen/sudoku-solver)
- [三国墨英传](https://chenyanchen.github.io/sango3-web/) — [source](https://github.com/chenyanchen/sango3-web)

Project repos publish under `/<repo>/`, so this repo must not contain a folder named after one of them. `robots.txt` lives here (only the root of the host counts) and lists each project's sitemap.

Plain HTML, no build step: GitHub Pages serves the `main` branch as is.
